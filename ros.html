Phase 1
EC2 Instance Setup
01
☁️ Launch EC2 Instance

Create an AWS EC2 instance with Ubuntu 20.04 LTS, t2.micro (free tier), and 30GB of EBS storage. Open ports 22 (SSH) in the security group.

02
🔄 Update System Packages

Connect via SSH and update all system packages before beginning the ROS installation.

bash · EC2 Terminal
sudo apt update && sudo apt upgrade -y
Phase 2
ROS Noetic Installation
03
📋 Configure Ubuntu Repositories & Sources

Setup your sources.list to accept software from packages.ros.org, then add the ROS GPG key for secure package verification.

bash · Setup sources.list
# Add ROS package source sudo sh -c 'echo "deb http://packages.ros.org/ros/ubuntu $(lsb_release -sc) main" > /etc/apt/sources.list.d/ros-latest.list' # Install curl (if not already installed) sudo apt install curl -y # Add ROS GPG key curl -s https://raw.githubusercontent.com/ros/rosdistro/master/ros.asc | sudo apt-key add -
04
📦 Install ROS Noetic Desktop-Full

Update package index then install the full ROS Noetic desktop package — includes 2D/3D simulators and perception packages for robotic development.

bash · Install ROS Noetic
# Update package index sudo apt update # Install ROS Noetic Desktop-Full (Recommended) # Includes: simulators, 2D/3D perception packages sudo apt install ros-noetic-desktop-full -y
05
⚙️ Environment Setup

Source the ROS setup script in every bash terminal. Add it to .bashrc so it loads automatically on every new terminal session.

bash · Environment Configuration
# Source ROS environment (run in every terminal) source /opt/ros/noetic/setup.bash # Add to .bashrc so it loads automatically echo "source /opt/ros/noetic/setup.bash" >> ~/.bashrc source ~/.bashrc # Verify ROS is installed correctly rosversion -d # Expected output: noetic
